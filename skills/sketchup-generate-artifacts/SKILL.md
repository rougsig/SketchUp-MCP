---
name: sketchup-generate-artifacts
description: Create or update SketchUp furniture artifacts in the SketchUp-MCP project, including Python generators, millimeter COLLADA meshes, native primitive JSON and model variants.
---

Work in the SketchUp-MCP repository. Read `scripts/generate_artifacts.py`, the target model's `artifacts/<model>/README.txt`, generator and `layout.py` when present. The archived `zr/` directory is a reference; maintained generators live in `artifacts/`.

Run existing generators with:

```sh
python3 scripts/generate_artifacts.py --geometry-only
python3 scripts/generate_artifacts.py laundry-sink --variant open
python3 scripts/generate_artifacts.py detergent-cabinet
```

Omitting models rebuilds all five models and their technical PNG previews with NumPy (`requirements-render.txt`). `--geometry-only` skips previews and needs no third-party packages. `--quality draft` uses the original standard-library PNG/SVG renderer. For sink and detergent variants, canonical `model-primitives.json` represents the closed model and contains data for variants; it does not represent the currently rendered open pose. The tower's `open` variant changes only the PNG preview, while its DAE/JSON remain closed.

For a new model, create `artifacts/<slug>/build_model.py`, optionally a `layout.py`, and a concise model README containing dimensions, assumptions, physical versus clearance bounds, variants and usage. Add the slug and variants to `VARIANTS` in the common CLI. Write all reproducible outputs (DAE, primitive JSON, PNG, SVG, exported SKP) to `artifacts/<slug>/cache/`, creating it when necessary. These directories are ignored by Git and excluded from build archives. Keep sources and documentation outside cache. Resolve the cache directory relative to `__file__` so commands work outside the repository cwd. Native builders and assembly examples consume `cache/model-primitives.json`; generate it before native execution. Honor `SKETCHUP_ARTIFACT_SKIP_RENDER=1` after writing geometry. Use standard-library Python for geometry when the existing mesh representation is sufficient. For previews, follow the existing generators' hook into `scripts/render_quality.py:render_preview`, honoring `SKETCHUP_ARTIFACT_RENDER_QUALITY`. Keep moving-part poses consistent with their requested variant before passing mesh records to the renderer.

Keep X=width, Y=depth, Z=height; dimensions in millimeters, COLLADA `unit meter="0.001"` and `Z_UP`. Generate actual meshes and JSON from the same geometry definitions. Use independent named groups for the frame, moving parts and service/clearance zones. Clearance volumes are reference geometry, not cabinet dimensions. Preserve panel thickness when changing dimensions; do not substitute whole-model scaling for parametric edits.

Prefer native `build_assembly` from JSON when the user needs editable parts or interactive opening; SketchUp DAE import flattens internal meshes. Keep the hatch glass, rim, handle and grip together in the `Door` group. Declare moving doors in `doors` with `group`, `hinge_mm`, `angle_degrees` and optional `rotation_axis`; drawers in `drawers` with `group`, `anchor_mm` and optional `travel_mm` (default 400). Custom groups use the `motions` dictionary with `rotation_axis`/`rotation_degrees` or `translation_mm`. Native assembly stores motion and an exact closed transform for each moving group. The extension's Artifacts MCP toolbar tool drags a picked door/drawer continuously between its closed and maximum positions, storing motion_fraction. Doors rotate around their hinge and drawers translate along their travel vector; releasing preserves the partial position, Esc aborts the gesture, and each drag is one Undo. MCP writes are blocked during a live drag. Its context menu toggles full open/closed motion, zones and the detergent cabinet RightSide cutaway. These are extension controls on ordinary components, not Dynamic Components. Test complete moving groups, partial positions, resumed dragging, travel limits, cancellation and exact closing in native SketchUp. tests/sketchup_drag_smoke.rb exercises native picking and mouse callbacks with the editable artifacts loaded, then restores their positions. Use positive signed volumes to check outward winding of closed DAE meshes. Keep display clearance planes 0.5 mm away from coincident furniture surfaces, documenting this separately from nominal clearance dimensions. Current washer/dryer handles project to Y=-13 mm; physical envelopes are 600×613×850 mm.

Existing archived JSON uses a material-color dictionary, optional group-name dictionary, and primitive shapes. `build_assembly` normalizes these project files. New inline MCP assemblies use typed material/group arrays: read `server/automation_schema.py` and `normalize_assembly` in `extension/sketch_up_mcp/automation.rb` before choosing a representation. Do not send archived dictionaries as typed inline arrays.

Validate generated JSON and XML, assert expected physical bounds, and render/inspect the requested variant. State conditional hardware dimensions as assumptions. A PNG inspection does not prove native SketchUp behavior. Do not create per-artifact Ruby builders; native creation belongs to the MCP bridge. For native assembly use `build_assembly` with an allowed `json_path`, stable `key` and fresh `operation_id`; updates use `replace:true`. A Ruby file can be run with `run_ruby_script` only after hashing its exact contents and checking configured automation folders. Return links to the model files and the preview with the dimensions actually checked.
